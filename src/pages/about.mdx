I focus on practical tools that solve daily problems without tracking, advertising, or unnecessary dependencies.

## What I build

Here are the main projects I work on:

- **[ClipVault](/products/clipvault/)**: An open-source Android clipboard manager and encrypted password vault licensed under GPL-3.0. It runs completely offline with no network permissions. You can inspect the source code on [GitHub](https://github.com/saurabh-vision/clipvault).
- **[ScanXpert](/products/scanxpert/)**: An Android application for document scanning and PDF utilities. It combines image capture, document editing, compression, and text extraction in one place.
- **[downloadfrom.app](https://downloadfrom.app)**: A web-based tool for downloading media files across many sites. It supports direct extraction without accounts or software installations. Note that YouTube is not supported.

## What I write

I write about software architecture, performance, and scaling patterns.

- **[How Systems Scale](https://howsystemsscale.substack.com)**: My newsletter where I break down real-world distributed systems, reliability challenges, and backend engineering choices.
- **[Articles](/posts/)**: Long-form guides and technical walkthroughs covering Android development, security practices, and system architecture.
- **[Notes](/notes/)**: Short snippets, bug fixes, and quick lessons learned while building software.
